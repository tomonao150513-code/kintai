# ADR-0003: 日跨ぎ記録は「開始日」に全時間を計上する（案A）

- ステータス: 承認（2026-09-07、§10 Q1）
- 関連要件: §7.2、F-PUNCH-11

## 背景

打刻は日をまたぐことがある（例: 23:30 開始 → 翌 01:00 終了）。集計・グラフ・エクスポートで
その 1.5 時間をどの日に計上するかを決める必要がある。

- 案A: 開始時刻の日付にその記録の全時間を計上する。
- 案B: 日付境界で按分し、各日に配分する（23:30〜24:00 を初日、00:00〜01:00 を翌日）。

## 決定

**案A** を採用する。`work_date = 開始時刻の JST 日付`。按分（案B）は実装しない。

## 理由

- 実装が単純で、集計・エクスポート・グラフすべてで一貫させやすい。
- 1 人運用で、日跨ぎ作業の頻度・重要度が低い。
- ユーザー合意済み（§10 Q1）。

## 影響

- `TimeEntry.work_date` プロパティと `services/aggregation.py` の `TruncDate("start_at", tzinfo=JST)` で統一。
- 将来、日別の正確性が必要になったら案B を追加する（本 ADR を Superseded にして新 ADR）。
