# ADR-0004: 実働時間は丸めなし・秒精度で保持し「◯時間◯分◯秒」で表示

- ステータス: 承認（2026-09-07、§10 Q3）
- 関連要件: §5.8 F-FMT、F-PUNCH-12/13

## 背景

勤怠システムでは 15 分単位などの丸めを入れることが多いが、本ツールは個人の作業実績把握が目的。
ユーザーは「1時間30分24秒 作業しました！」のような秒までの表示を希望。

## 決定

- 実働時間は `end_at - start_at` の実値（秒精度、ミリ秒以下切り捨てのみ）。**時間・分への丸め／切り上げは行わない。**
- 保持・受け渡しは「秒（int）」。
- 画面表示は `format_hms()`: `h>0 → {h}時間{m}分{s}秒` / `h==0,m>0 → {m}分{s}秒` / それ以外 `→ {s}秒`。
- 終了打刻直後に `greeting_message()` =「お疲れ様でした！ {hms} 作業しました！」を表示。
- CSV/Excel は集計しやすさのため `実働秒数`(int) と `実働時間(HH:MM:SS)` と `実働時間(h)`(小数2桁) を併記。

## 理由

- ユーザー要望（§10 Q3）。
- 丸めがないほうがロジックが単純で、テストも表で書ける。
- 秒・HH:MM:SS・小数h を出しておけば表計算側でどうとでも再集計できる。

## 影響

- 丸め設定は持たない。将来必要なら「表示専用の丸めオプション」を足す（保存値は据え置き）。
- 集計（`aggregation.py`）も DB 側で丸めない。`format_hours_decimal` の小数2桁だけは表示上の丸め。
