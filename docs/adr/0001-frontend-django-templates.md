# ADR-0001: フロントエンドは Django テンプレート + Bootstrap + Chart.js

- ステータス: 承認（2026-09-07）
- 関連要件: §9、F-AGG-06

## 背景

当面ユーザー 1 人・ローカル運用の小規模ツール。画面数は 10 程度。グラフ表示が必要。

## 決定

SPA（React 等）を採用せず、**Django のサーバーサイドテンプレート + Bootstrap 5** で画面を作る。
グラフだけ **Chart.js** を使い、集計データは素の `JsonResponse` を返すエンドポイントから fetch する。
DRF は導入しない。フロントのビルドツール（npm/webpack/vite）も導入しない。

## 理由

- 画面遷移中心の CRUD で SPA の利点が薄い。学習・構築・デプロイのコストが下がる。
- 認証・CSRF・フォームバリデーションを Django 標準にそのまま乗せられる。
- 1 人運用でリアルタイム性要求がない。
- Chart.js は CDN or 単一ファイルで足り、JSON さえ返せば描ける。

## 影響

- JS は最小限（経過秒カウントアップ、確認ダイアログ、グラフ fetch/描画）。
- 将来チーム化・リッチ UI 化する場合は、`stats_*` エンドポイントを DRF 化して SPA を別途載せる余地は残る（本 ADR を置き換える）。
